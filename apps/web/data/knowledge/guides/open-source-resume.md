## What to put on a resume for LFX, GSoC or Outreachy

- **Header:** name, email, GitHub, LinkedIn, portfolio, location and timezone.
- **Open source contributions first**, if you have any: project, what you did, and a link to the PR, plus status (merged, open). Example: "Kyverno: fixed a nil-pointer panic in the cleanup controller (PR #…, merged, cherry-picked to 1.17)".
- **Skills:** the languages and tools the project uses, listed honestly (Go, Kubernetes, React, CI…).
- **Projects:** 2–4 with links and a one-line impact each.
- **Education:** degree, year, university.
- **Experience:** internships, jobs, hackathons, talks, blog posts about open source.

Keep it to one page if you can, two at most. Export a PDF with clickable links, and tailor the order to each project.

## Make your GitHub profile work for you

- Pin the repositories and forks you contributed to.
- Add a profile README with a short intro and links to your best PRs.
- Use descriptive commit messages and PR descriptions. Mentors read them.
