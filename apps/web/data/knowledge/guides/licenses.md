## What makes software open source

Open source software is published under a licence that lets anyone use, study, change and share it, as defined by the [Open Source Initiative](https://opensource.org/osd). The licence is what makes code open source. Code that is public on GitHub with no licence is not.

## Open source licenses compared: MIT, Apache, BSD, MPL, GPL, AGPL (permissive vs copyleft)

| Licence               | Type             | In short                                                                               |
| --------------------- | ---------------- | -------------------------------------------------------------------------------------- |
| **MIT**               | Permissive       | Do almost anything; keep the copyright notice.                                         |
| **Apache-2.0**        | Permissive       | Like MIT, plus an explicit patent grant and a NOTICE file. Used by most CNCF projects. |
| **BSD-2/3-Clause**    | Permissive       | Like MIT; the 3-clause version forbids using the authors' names for endorsement.       |
| **MPL-2.0**           | Weak copyleft    | Changes to MPL files must stay open; you can combine them with closed code.            |
| **LGPL**              | Weak copyleft    | Libraries: linking is allowed; changes to the library must stay open.                  |
| **GPL-2.0 / GPL-3.0** | Strong copyleft  | If you distribute a derived work, its source must also be GPL.                         |
| **AGPL-3.0**          | Network copyleft | Like the GPL, and offering the software over a network also counts as distributing it. |

Documentation and content often use Creative Commons licences (CC BY 4.0, CC BY-SA 4.0). Pick a licence for your own project at [choosealicense.com](https://choosealicense.com).
