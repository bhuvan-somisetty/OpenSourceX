# Contribution Intelligence

Status: Phase 2 (D-011). The MVP has basic PR metadata only (counts, recent
and merged activity, links). For a PR the system collects the linked issue, changed files,
commits, tests touched and review comments, then presents: problem, files
and why they matter, component touched, tests, review discussion, and what
to understand before explaining it. Everything is cited to the PR/issue.
Root-cause statements are labeled inference unless the author or a
maintainer stated them. It supports understanding, not fabricating.
