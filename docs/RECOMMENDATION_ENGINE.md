# Recommendation Engine

Rule-based and explainable. Inputs: languages, technologies, programs of
interest. Each candidate gets a list of reasons, each tied to a fact with
provenance ("Go matches your language", "Participated in LFX 2024 Summer",
"CONTRIBUTING.md found"). Ordering uses the count and weight of matched
reasons; the weights are shown. No hidden score. Missing data is stated
("activity could not be verified"), not assumed.
