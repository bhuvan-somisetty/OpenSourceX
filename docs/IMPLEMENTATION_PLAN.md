# Implementation Plan

Status values: Planned / In progress / Done (verified). Nothing below is
implemented yet.

- **M0 Foundation (Planned):** pnpm workspace, CI, lint, typecheck, Postgres
  compose, migrations. Done when CI is green.
- **M1 Ingestion (Planned):** GSoC and LFX adapters, snapshots,
  normalization, provenance, tests on recorded responses. Done when
  2023-2026 data loads with provenance.
- **M2 API (Planned):** programs, projects, history endpoints, validation.
- **M3 GitHub intelligence (Planned):** analyze, activity evidence,
  contribution-guide detection, SSRF-safe.
- **M4 Web (Planned):** landing, discover, program, project, analysis, all
  UI states, accessibility checks.
- **M5 Learning + Interview (Planned):** learning levels 1-3, interview
  mode with grounded evaluation and injection tests.
- **M6 Quality pass and audit (Planned).**

Definition of done: tests, lint, typecheck and build pass; docs updated; no
fake data; all UI states implemented; security reviewed.
